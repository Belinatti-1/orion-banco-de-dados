# Orion Bootcamp — Banco de Dados

Repositório destinado à realização dos exercícios práticos de Banco de Dados do Orion Bootcamp.

## Tecnologias
- PostgreSQL
- MongoDB
- Docker e Docker Compose
- SQL e NoSQL

## Exercícios

1. **SQL Básico:** criação de tabelas, chaves primárias, chaves estrangeiras e inserção de dados.
2. **JOINs e Filtros:** consultas relacionais com INNER JOIN, LEFT JOIN, WHERE e UPDATE.
3. **MongoDB — CRUD Básico:** criação de coleções, inserção e consulta de documentos.
4. **MongoDB — Consultas Avançadas:** atualização de documentos e consultas com arrays e filtros.

## Ambiente

Os bancos de dados são executados em containers Docker, utilizando o arquivo `docker-compose.yml` disponibilizado pelo Orion Bootcamp.
